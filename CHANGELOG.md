# Changelog

## 0.1.0 - 2026-09-05

- Initial public packaging as `diagif`, with the `diagif` command.
- Grounded research, bounded model calls, resumable run artifacts, scene inspection
  and a critic with explicit unmeasured checks when vision is unavailable.
- Deterministic scene rendering with bundled fonts and icons, seamless animation,
  Pillow fallback, quality reports and contact sheets.
- Neutral gallery scenes, optional LinkedIn URL footers and generated mind maps.
- Public documentation, licence notices, sanitisation checks and Windows/Linux CI.

The public example gallery and refreshed render measurements are release tasks.
